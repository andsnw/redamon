# Rules of Engagement

Client: Northwind Trading.

## Permitted activities

The only activities authorised under this engagement are:

1. **Domain and subdomain discovery** - enumerating the names the organisation exposes
2. **HTTP probing** - determining which of those names answer, and what they serve

No port scanning. No resource enumeration. No vulnerability scanning. No
JavaScript analysis. Anything not listed above is out of scope.
