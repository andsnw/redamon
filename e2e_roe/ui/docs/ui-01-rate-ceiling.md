# Rules of Engagement

Client: Acme Retail Ltd.

## Rate of testing

All testing must be conducted at no more than **3 requests per second** in total
across every tool. This is an aggregate ceiling, not a per-tool allowance. The
target's origin is modest and the operations team has asked for a gentle pace.

## Scope

The scope is as agreed in the signed order form. Do not add hosts to it.
