# Engagement Letter — Contoso Manufacturing

Contoso Manufacturing engages the tester to assess its external estate.

The estate belongs to Contoso, not to the tester.

## Rate

This letter deliberately states **no aggregate rate limit**. The tester is asked
to use professional judgement.

## Note for the record

This document exists to prove a point about defaults: an engagement against
somebody else's estate with no stated ceiling must not silently run unlimited.
